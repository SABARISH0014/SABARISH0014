## `01` 🌍 SDG TRAJECTORY

### **Global Outcome Forecaster**

> **AI + Data Engineering + 3D Visualization + Policy Simulation**

An AI-driven platform designed to track, forecast and simulate global progress toward the United Nations Sustainable Development Goals.

The system combines historical and live data, machine learning, interactive visualization and AI-assisted policy recommendations.

**What makes it interesting**

```text
🌍 Interactive 3D global visualization
🤖 ML-based 2030 forecasting
🔎 Automated anomaly detection
📊 Multi-source ETL pipeline
🧠 AI Policy Copilot
🎛️ Policy simulation engine
🔐 Secure administration
⚙️ GitHub Actions data synchronization
☁️ Cloud-based deployment
```

**Architecture**

```text
Global Data Sources
       │
       ↓
   ETL Pipeline
       │
       ↓
Data Cleaning + Anomaly Detection
       │
       ↓
      Turso
       │
       ├──────────────→ ML Forecasting
       │
       ├──────────────→ Policy Simulation
       │
       └──────────────→ AI Policy Copilot
                              │
                              ↓
                     React Visualization
                              │
                              ↓
                         3D Globe
```

**Stack**

`React` · `Vite` · `FastAPI` · `Python` · `Scikit-Learn` · `Pandas` · `NumPy` · `Three.js` · `Tailwind CSS` · `Turso` · `GitHub Actions` · `Vercel` · `Render`
